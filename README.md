# Campus Event Hub

A modern static landing page for a university event platform. This project showcases upcoming campus activities such as coding competitions, talent shows, and innovation events in a clean and attractive design.

## Overview

Campus Event Hub is a responsive HTML/CSS website designed to help students discover and register for campus events. It highlights featured events, explains the purpose of the platform, and includes a contact/registration section for interested attendees.

## Features

- Hero section with a strong campus-event branding message
- Event cards for ongoing and upcoming activities
- About section describing the platform's purpose
- Registration form for event interest and participation
- Responsive layout built with HTML and CSS

## Project Structure

- `index.html` – main page structure and content
- `style.css` – styling, layout, colors, and responsiveness
- `README.md` – project documentation

## How to Run

Because this is a static website, you can view it by opening `index.html` directly in a browser.

For a local web server, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
